### 1️⃣ RAGForge — Intelligent Technical Knowledge Assistant

**End-to-end Retrieval-Augmented Generation system for technical Q&A with citations**

**Stack:** React · TypeScript · Python · FastAPI · Supabase · PostgreSQL · pgvector · Gemini

**What I built:**
- Hybrid retrieval combining semantic search (pgvector) and keyword search (BM25)
- Intelligent reranking before LLM generation
- Citation-grounded answers with source traceability
- Retrieval inspection and debugging workflows
- RAG evaluation metrics: Recall@K, MRR, faithfulness, answer relevance

**Architecture:**
```text
Documents → Chunking → Embeddings
                         ↓
          ┌──────────────────────────┐
          ↓                          ↓
     pgvector                    BM25
   (Semantic)                 (Keyword)
          ↓                          ↓
          └────────────┬─────────────┘
                       ↓
              Hybrid Retrieval
                       ↓
                  Reranking
                       ↓
                 Gemini LLM
                       ↓
        Citation-Grounded Answer
```

**Why it matters:** Demonstrates mastery of modern RAG—vector databases, embeddings, hybrid search, reranking, and LLM integration. Production-ready system architecture.
